# 1.2. Participações (Modelagem)

Esta página consolida as participações e contribuições dos membros na Entrega 02, dedicada ao módulo de Desenho de Software (Modelagem). O registro deve conectar cada contribuição aos relatórios, artefatos UML, versionamentos, commits, reuniões e demais evidências produzidas por cada subequipe.

O padrão de preenchimento segue a mesma lógica usada na entrega anterior: identificar o membro, descrever a contribuição, avaliar a significância e apontar comprobatórios claros. Os conteúdos específicos desta entrega devem priorizar Modelagem Estática, Modelagem Dinâmica, pontos de vista sobre IA Generativa, versionamentos e rastreabilidade com os relatórios.
